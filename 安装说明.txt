Yunindex阅读统计 v2.2 · 单页版安装说明
======================================================

适配：KPW6 / 5.19.03 / Vera 越狱。无需 KUAL，Vera 自带 KPM，`;log runme` 有效。

面板内容：今日 / 本周阅读 / 本月日均 / 连续阅读
        + 本周节奏柱图 + 本年统计（累计时长 / 天数 / 在读 / 完成）+ 金句。

封面（书封面，独立于背景）：桌面 logo.png（1258×1676 RGB）作为「书封面」，
      独立文件为 ui/cover.png，launcher 头部 `# Icon:` 指向它 → 装好后图书馆/主页里
      「Yunindex阅读统计」会像一本带封面的书平铺显示（Vera Scriptlet 机制）。
      dashboard 打开后的背景仍是原 generate_bg.py 输出（ui/dashboard_bg.png），未被改动。

卸载（务必看）：Vera 越狱的 `;log` 不支持 uninstall，本插件改用「标记文件 + ;log runme」
方案——详见文末【如何卸载】章节。

------------------------------------------------

安装步骤
------------------------------------------------
1. 安装时，把【这三样】复制到 Kindle 的 USB 根目录 /mnt/us/（说明文档可不复制）：

     /mnt/us/
     ├─ RUNME.sh                        ← 入口，必须在根
     ├─ UNINSTALL.sh                    ← 卸载脚本（与 RUNME.sh 同在根）
     └─ native-reading-time-package/    ← 安装包（必须直接在根）

   ⚠️ 仓库根还有个 `uninstall.flag`（0 字节空文件），它是【卸载信号】——
      安装时【千万不要】把它拖进 Kindle！一旦它出现在 /mnt/us/ 根，
      ;log runme 会被误判为「卸载」而非「安装」。
      uninstall.flag 只在卸载时单独使用（见下方【如何卸载】）。
        ├─ Yunindex阅读统计.sh / Install-Native-Reading-Time.sh
        ├─ native-reading-time-daemon.sh / .conf
        ├─ NotoSerifSC-Regular.otf / -Bold.otf / FONT-LICENSE.txt
        └─ ui/  (compose.py / dashboard_bg.png / cover.png / quotes.tsv)

   ⚠️ 千万不要删 /mnt/us/reading-time/ —— 里面是阅读明细数据（见文末 FAQ）。
      覆盖安装即可，安装器会自动备份 .bak-时间戳 并原样保留。
   ⚠️ UNINSTALL.sh 必须与 RUNME.sh 一起复制到 USB 根（两者同一目录）。
      否则将来无法通过 RUNME.sh 卸载（详见文末【如何卸载】）。
   ⚠️ 复制后务必「安全弹出」再拔线，否则文件可能只留在电脑缓存没写入。

2. 拔线，首页搜索栏输入（不带引号）：
       ;log runme
   回车。

3. 安装器自动完成：探测 FBInk / Python3+Pillow（快通道，缺失则降级纯 fbink
   慢通道）、装守护进程 + 字体 + 单页背景图到 /mnt/us/reading-time/、
   装 Upstart 任务并启动、自动 chmod +x UNINSTALL.sh 供后续卸载。
   任何失败都会把日志导出到 USB 根 LOG-install.log。

4. 顶部 toaster 出现：
       Yunindex阅读统计 v2.2 installed
   即成功。打开方式：图书馆/主页会多出一本带 logo 封面的书「Yunindex阅读统计」，
   点击它即可打开 dashboard。

------------------------------------------------
如何卸载（务必看完）
------------------------------------------------
Vera 越狱（KPW6 / 5.19.03）的 `;log` 只支持 mrpi / runme 两个 action，**不支持 uninstall**。
本插件改用「标记文件 + 同一个 ;log runme 入口」：

  1. 交付目录（或 GitHub 仓库）里已带好标记文件 `uninstall.flag`（0 字节空文件）。
     想卸载时，把它和 UNINSTALL.sh 一起拖到 USB 根（/mnt/us/，与 RUNME.sh 同级）。
     · 文件名兼容 uninstall.flag / uninstall.flag.rtf / uninstall.flag.txt（RUNME.sh
       已改为通配匹配），无需纠结扩展名。
  2. 安全弹出 Kindle，搜索栏输入 `;log runme` 回车。
  3. RUNME.sh 检测到标记文件 → 自动调起 UNINSTALL.sh → 弹 toaster 提示
     "Reading time tracker uninstalled"，并删掉自身 + 所有 uninstall.flag* 变体。

卸载时阅读数据（reading-time.tsv 等）原位保留、不删除，重装后自动续用，无需手动拖回。

------------------------------------------------
如何确认装的是新版（而非旧残留）
------------------------------------------------
· 看 toaster：含 **v2.2** 才是本版（旧版无版本号）。
· 或看安装日志：
      tail -n 5 /mnt/us/reading-time/install.log
  本版首行会打出：
      installer v2.2 (single-page / no-touch / SerifSC-only) entered
  若看到的是旧格式或无此标记，说明 Kindle 跑的还是旧代码。

------------------------------------------------
排错
------------------------------------------------
- 完全没反应（无 toaster、无 LOG-install.log）：
    · 先确认 RUNME.sh 与 native-reading-time-package/ 都直接在 USB 根；
    · 确认已「安全弹出」；
    · 仍无效 → 用文末「手动安装」绕过 ;log runme。
- 有 toaster 但安装失败：USB 根会生成 LOG-install.log，拷回电脑看具体原因。
- 卸载时提示 "UNINSTALL.sh not found; reinstall first"：UNINSTALL.sh 没同步到
  /mnt/us/，在电脑把它复制到 USB 根再次 ;log runme 即可。
- 需要 Vera 越狱（自带 KPM + FBInk）；无需 KUAL。
- 「累计时长」= 本年累计（与 v12.0 年度页一致）；要改「本月累计」请告知。

------------------------------------------------
数据安全 FAQ
------------------------------------------------
- /mnt/us/reading-time/reading-time.tsv = 插件逐日累积的阅读明细
  （后台 daemon 从系统 lipc 实时读数写入）。覆盖安装时安装器自动备份
  为 .bak-时间戳 并原样保留，无需手动删。
- Kindle 系统原生阅读记录（设置→阅读时长、每本书进度/时长）在系统侧，
  **不在 /mnt/us/reading-time/ 内**，删这个目录不会影响它。
- 若已误删：系统记录无恙，仅插件逐日明细清空，daemon 重启后从系统
  重新累积，几天后恢复完整。

------------------------------------------------
手动安装（;log runme 完全没反应时的备选）
------------------------------------------------
在 Kindle 终端（SSH / KOReader 终端 / Vera 终端）以 root 执行：
      /bin/sh /mnt/us/native-reading-time-package/Install-Native-Reading-Time.sh
成功会弹 toaster；失败则在 USB 根生成 LOG-install.log。
（无 root 时先 `id` 确认 uid，必要时 `mntroot rw` 后 sudo/su。）
